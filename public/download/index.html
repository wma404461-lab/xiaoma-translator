01 / Windows

桌面随译

自动跟随前台有音频的应用。耳机可用，字幕独立悬浮在软件上。

下载 Windows 版 ↓ ZIPv0.2.0 · Windows 10 / 11 · 64 位

解压后先运行 Setup-FlowSub.cmd，完成本地模型安装；以后双击 Start-FlowSub.cmd。需 Python 3.12，建议 16 GB 内存和 NVIDIA GPU。首次配置下载约 5 GB。

02 / Android · 公开测试版

随身字幕

手机本地识别与语义翻译。透明字幕可拖动，保留退出按钮。

下载 Android 版 ↓ APKv0.2.0 · Android 10+ · 64 位

首次下载本地模型约 1.47 GB，建议 Wi-Fi、8 GB 内存与 3 GB 空闲存储。允许悬浮窗并确认系统音频捕获后使用。实际手机延迟与长时间稳定性仍待实机验收。

字幕先定稿，再显示。

粗体白字、黑色描边，小号英文紧贴中文。已显示中文不反复改写，减少闪烁。识别、分句和 AI 推理都会产生延迟。

首次安装后，本地运行。

音频不上传、不读取麦克风，不用付费 API。桌面版用 Qwen3 4B，手机版用更小的 Qwen3 1.7B；不同设备的速度和翻译质量会有差异。

软件里即可更新。

Windows 点字幕窗里的“更新”；Android 点“检查更新”。下载支持续传，安装前自动验证。模型会保留，安卓安装由系统确认。

知道哪些地方有边界。

部分安卓应用禁止捕获音频。多个视频同时发声可能混音，建议暂停不看的视频。系统授权、受保护画面和硬件性能均会影响体验。
