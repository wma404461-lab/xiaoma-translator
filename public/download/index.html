02 / Android · Public Test Version

Portable Subtitles

On-device local recognition and semantic translation on mobile. Transparent subtitles are draggable, with exit button preserved.

Download Android Version ↓ APKv0.2.0 · Android 10+ · 64 bits

First-time local model download takes about 1.47 GB, Recommended Wi-Fi, 8 GB Memory and 3 GB Available free storage. Allows floating windows and confirms system audio capture for use. Actual mobile latency and long-term stability still pending real-device testing.

Subtitles finalized first, then displayed.

Bold white text with black outline, small English text tightly adjacent to Chinese. Once displayed, Chinese text is not rewritten, reducing flickering. Recognition, sentence segmentation, and AI Inference all introduce latency.

After first installation, run locally.

Audio not uploaded, microphone not accessed, no cost involved API.Use desktop version Qwen3 4B, Use mobile version with smaller Qwen3 1.7B; Performance and translation quality may vary across devices.

Updates available directly in the software.

Windows Click ’Update’ in the subtitle window”; Android Click ’Check for Updates’”.Supports resume download; automatically verifies before installation. Models are retained; Android installation requires system confirmation.

Knows where boundaries exist.

Some Android apps block audio capture. Multiple videos playing simultaneously may cause audio mixing. Pause videos you don’t want to watch. System permissions, protected content, and hardware performance all affect the experience.
